# Samples

`aalekh_resume.tex` — a reconstruction of Aalekh's resume in the
`resume-openfont` template, used to exercise the pipeline offline. It is built
from the structure and content of the real resume, not a copy of the file
itself; replace it with your actual `.tex` when you run the app.

`jd_google_backend.txt` — a representative senior backend posting with the
shape real postings have: minimum qualifications, preferred qualifications and
responsibilities in separate blocks. The extractor uses those headings to tell
a hard requirement from a nice-to-have.
